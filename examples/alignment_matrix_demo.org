=== Key Insights ===

• Contain mode: Alignment positions the scaled media within the letterboxed space
• Cover mode: Alignment controls the crop focus - which part of the image remains visible
• Default (no alignment): center/middle for both modes
• VALIGN values: top, middle, bottom
• ALIGN values: left, center, right

Try different combinations to achieve the desired visual result!
