=== SVG Size Detection ===

pagemaker uses a 3-tier detection strategy:

1. ViewBox + dimensions: If viewBox and width/height attributes exist, they define intrinsic size

2. Explicit dimensions: If only width/height exist, use those values

3. Content bounding box: Analyze SVG elements to compute natural size

This ensures proper scaling regardless of how the SVG was created.

=== Fit Modes ===

SVG elements support contain mode only. Non-contain fit values are ignored with a warning.

Use :ALIGN: and :VALIGN: to position the SVG within its frame.
